# Simulation Dataset

This folder contains the building performance simulation datasets generated from the different variables in a facade model.

## Data Generation

Facade design parameters are systematically varied in Grasshopper and evaluated using Honeybee and EnergyPlus under fixed building geometry, weather conditions, occupancy, and operational assumptions.

## Input Variables

The proposed facade design variables include:

- Window-to-Wall Ratio (WWR)
- Glazing U-value
- Solar Heat Gain Coefficient (SHGC)
- Shading depth

## Output Variable

The primary performance indicator is:

- Energy Use Intensity (EUI), kWh/m²·year

## Dataset Structure

The simulation dataset will contain one row for each facade design case.
